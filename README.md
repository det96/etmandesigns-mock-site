# EtmanDesigns

Review mock of the EtmanDesigns site for David Smith. This is not a live website. Do not deploy it, turn on GitHub Pages, or publish it.

## Quick look: just double-click index.html

Open `index.html` from the project folder. Styles, images, fonts, and the menu script load without a server.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

Production build:

```bash
npm run build
npm run preview
```

`npm run preview` also serves on http://127.0.0.1:4317. The built `dist/index.html` can be opened directly from disk as well.
